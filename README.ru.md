# Murmura

**Открытый движок хореографии дрон-шоу.** Строит фигуры, планирует безопасные
переходы, создаёт световые программы и экспортирует готовые файлы шоу `.skyc`.
Работает из YAML-сценария, из Python или прямо в Blender через собственный аддон.

> *Мурмурация* - это стая скворцов, которая движется как единое целое. Murmura делает то же самое с дронами.

## Возможности

- **Экспорт и импорт `.skyc`**: траектории в виде кривых Безье, байткод светодиодов,
  управление рысканьем (yaw), пиротехника, метки времени, камеры, геопривязка
  и музыка. Файлы открываются в существующих просмотрщиках `.skyc` и наземных станциях.
- **Безопасные переходы между фигурами**: оптимальное назначение дронов на точки
  и выбор самого быстрого безопасного плана из трёх: синхронного, со *сдвигом
  старта* (задержки отдельных дронов) и *по дорожкам* (временные слои по глубине
  или высоте). Каждый план проверяется симуляцией.
- **Взлёт и посадка**: многослойный взлёт для плотных сеток, возврат через
  «площадку-сцену», посадка очередями с учётом остановки моторов, умный RTH.
- **Фигуры**: сетка, линия, круг, многоугольник, звезда, сердце, спираль, диск,
  прямоугольник, сфера, куб, тор, спираль-геликс, текст (латиница и кириллица),
  SVG (пути, дуги, трансформации, цвета) и изображения.
- **Световые эффекты**: цвет, цвета фигуры, градиент, радуга, пульсация, волна,
  мерцание, затухание; автоматическое упрощение ключей; точный байткод 50 кадров/с.
- **Движение фигур**: вращение, «дыхание», волна; автоматически смягчаются,
  чтобы не выйти за ограничения скорости и ускорения.
- **Проверка безопасности**: высота, горизонтальная и вертикальная скорость,
  ускорение, минимальная дистанция между дронами в воздухе, минимальная высота
  во время шоу, скорость рысканья; отчёт в PDF.
- **Аддон для Blender**: дроны, фигуры, сценарий (storyboard) и сборка шоу одной
  кнопкой с записью точных ключей Безье, проверка безопасности, экспорт и импорт
  `.skyc`. Работает на встроенном Python Blender без дополнительных пакетов.
- **Сервер планирования**: HTTP API, совместимый с дополнением Skybrush Studio для
  Blender. Укажите в дополнении `http://localhost:8000`, и Blender будет
  считать переходы, взлёт, посадку, RTH, SVG-фигуры, графики проверки и экспорт
  `.skyc`/CSV через Murmura.
- **Предпросмотр**: отправка шоу в запущенный просмотрщик на этом компьютере.

## Установка

Нужен Python 3.10 или новее.

```bash
git clone https://github.com/Styans/murmura.git
cd murmura
pip install -e ".[all]"
```

## Быстрый старт

```bash
murmura demo -o demo.skyc --csv demo.zip --report demo.pdf
murmura build examples/hello.yaml -o hello.skyc --report hello.pdf
murmura preview hello.skyc
```

Формат сценария описан в [docs/show-script.ru.md](docs/show-script.ru.md).

Сообщения, отчёт о проверке, справка `--help` и PDF-отчёт выводятся на русском,
если Windows на русском (или задана переменная `MURMURA_LANG=ru`). Язык можно
указать явно: `murmura --lang ru ...` или `murmura --lang en ...`.

## Команды

| Команда | Назначение |
| --- | --- |
| `murmura build СЦЕНАРИЙ.yaml -o show.skyc` | собрать шоу из сценария (`--csv`, `--report`, `--preview`, `--strict`) |
| `murmura demo -o demo.skyc` | собрать демо на 100 дронов |
| `murmura serve --port 8000` | запустить сервер планирования для Blender |
| `murmura inspect show.skyc --validate` | сводка по `.skyc`, CSV-архиву или сценарию |
| `murmura validate show.skyc --min-distance 2.5` | проверка безопасности |
| `murmura convert show.skyc show.zip` | конвертация `.skyc` / CSV `.zip` / `.json` / `.pdf` |
| `murmura preview show.skyc` | открыть шоу в запущенном просмотрщике |
| `murmura formation heart -n 200 -p size=60` | выгрузить фигуру в CSV `Name,x,y,z,R,G,B` |

## Аддон для Blender

```bash
python blender/build_addon.py        # -> dist/murmura-blender-0.1.1.zip
```

Установка в Blender 4.2+: *Edit → Preferences → Get Extensions* → меню в правом
верхнем углу → *Install from Disk…* → выбрать zip. Появится вкладка **Murmura**
в боковой панели 3D-вида (клавиша `N`). Интерфейс аддона полностью переведён на
русский: язык выбирается в панели «Дроны» (Авто / Русский / English) и
работает, даже если сам Blender на английском.

1. **Дроны** - создать дронов на стартовой сетке (цвет каждого дрона = цвет объекта).
2. **Фигуры** - добавить фигуру: геометрия, текст (кириллица тоже), SVG,
   картинка или любой меш (одна вершина = один дрон).
3. **Сценарий** - выстроить фигуры по порядку, задать время удержания, свет и движение.
4. **Собрать шоу** - взлёт, безопасные переходы, свет и посадка рассчитываются и
   записываются в ключи анимации, которые точно повторяют рассчитанные кривые.
5. **Безопасность и экспорт** - проверка, экспорт/импорт `.skyc` и CSV,
   предпросмотр в просмотрщике (также *File → Export / Import*).

Анимацию после сборки можно править вручную: экспорт всегда снимает то, что
реально показывает Blender. Подробности: [docs/blender-addon.ru.md](docs/blender-addon.ru.md).

## Работа с дополнением Skybrush Studio

```bash
murmura serve --port 8000
```

В Blender: *Preferences → Add-ons → Skybrush Studio* → локальный сервер
`http://localhost:8000`. Дальше дополнение работает как обычно. Документация API
доступна по адресу `http://localhost:8000/docs`, подробности в
[docs/server-api.md](docs/server-api.md).

## Как обеспечивается безопасность переходов

1. Дроны назначаются на точки новой фигуры по минимуму суммы *квадратов*
   расстояний. Так рой сохраняет структуру в полёте, и почти исчезают опасные сближения.
2. Каждый дрон летит по прямой с плавным разгоном и торможением; длительность
   считается из ограничений скорости и ускорения, сегмент записывается точно
   как кубическая кривая Безье.
3. Если пути сближаются меньше `min_distance`, планировщик симулирует варианты
   со сдвигом старта и с дорожками и выбирает самый быстрый безопасный.
4. Посадка: рой выстраивается в увеличенную копию посадочной сетки, затем
   равномерно сжимается к ней и садится очередями.
5. Готовое шоу целиком проверяется по всем ограничениям.

## Отказ от ответственности

Murmura - независимый проект, не связанный с CollMot Robotics и проектом
Skybrush. Название Skybrush используется только для указания совместимости
форматов и API. Дрон-шоу - деятельность повышенного риска: всегда проверяйте шоу,
оставляйте запас безопасности, соблюдайте местные правила и проводите тестовые
полёты в безопасном месте.
