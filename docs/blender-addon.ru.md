# Murmura для Blender

Аддон для Blender 4.2+ (проверен на 5.2) для создания дрон-шоу в духе Skybrush
Studio: рой → сценарий из фигур → одна кнопка «Пересчитать шоу» → проверка →
`.skyc`. Сервер и дополнительные пакеты не нужны. Тяжёлые расчёты выполняются
**только** по кнопке «Пересчитать шоу», поэтому Blender не тормозит, пока вы
редактируете сцену.

## Установка

`python blender/build_addon.py` → `dist/murmura-blender-0.1.0.zip`. В Blender:
*Edit → Preferences → Get Extensions → (меню справа сверху) Install from Disk…*.
Вкладка **Murmura** появится в боковой панели 3D-вида (клавиша `N`). Язык
интерфейса выбирается вверху вкладки «Рой» (Авто / Русский / English).

## 1. Рой

Количество дронов, шаг стартовой сетки, число столбцов и **размер дрона** →
**Создать дронов**. Дроны попадают в коллекцию `Drones`, их цвет - это цвет
объекта (в режиме *Solid* выберите *Color: Object*).

**Группы дронов**: выделите дронов в окне и нажмите **+** - появится группа.
Кнопки *Добавить / Убрать / Выбрать* меняют её состав и выделяют её дронов.
Группу можно указать у любой фигуры - тогда летит только она, остальные
держат позицию и свой свет.

## 2. Сценарий

Кнопки сверху:

* **Взлёт** - плавный вертикальный взлёт с площадки. Настройки: высота,
  скорость набора (около 1-1.5 м/с экономно для батарей), *Слои* - дроны,
  стоящие ближе минимальной дистанции, взлетают на разную высоту. Если вы
  не добавили взлёт, он вставится **автоматически** перед первой фигурой.
* **Фигура** - из выделения:
  - в режиме редактирования (**Tab**) - из выделенных вершин (аддон сам
    создаёт группу вершин, так что выделение не потеряется);
  - один объект - все его вершины (точки Pointille / dronegen, любой меш,
    пустышка - её положение);
  - несколько объектов - они собираются в коллекцию-фигуру.
* **Посадка** - возврат к площадке и посадка очередями. Если её нет, она
  добавится автоматически в конце.

Список сцен можно переставлять (стрелки), дублировать, удалять, а кнопка с
часами переходит к началу сцены на таймлайне. После пересчёта рядом с каждой
сценой видны её кадры, на таймлайне появляются метки.

У фигуры настраиваются: откуда брать точки (объект / группа вершин /
коллекция), группа дронов, удержание, минимальная длительность перехода,
фиксированный старт (под музыку), свет и движение (вращение, дыхание, волна).

Если точек больше, чем дронов, берётся равномерная выборка. Если меньше -
лишние дроны ждут на месте с выключенным светом.

**Пересчитать шоу** - рассчитывает всё: назначение дронов на точки, переходы
без столкновений (синхронно, со сдвигом старта, по дорожкам, «сначала по
вертикали», через растяжку - выбирается самый быстрый безопасный вариант),
свет, возврат и посадку. Результат записывается в анимацию дронов.

## 3. Свет

* **Цвета объекта** (по умолчанию): цвет точек Pointille / dronegen
  (атрибут `drone_color`), иначе цвет вершин, текстура или цвет материала
  объекта под каждой точкой. Объект для цвета можно указать в поле
  *Цвет из* (по умолчанию - сама фигура или её родитель). *Мин. яркость*
  не даёт тёмным местам погаснуть ночью.
* **Не менять свет**, цвет, градиент, радуга, пульсация, волна, мерцание,
  переход цвета.
* **Покраска**: выделите дронов, выберите цвет и нажмите *Покрасить
  выделенных* - покраска запоминается в сцене на текущем кадре и
  сохраняется при каждом пересчёте. Крестик сбрасывает покраску сцены.

## 4. Безопасность

Минимальная дистанция, скорости (горизонтальная, вертикальная, набор),
ускорение, высоты, **темп переходов** (доля от лимитов: меньше - спокойнее
и экономнее для батарей), скорость посадки, остановка моторов, растяжка
сетки перед посадкой. **Проверить шоу** и кнопка-лупа «к первой проблеме».

## 5. Экспорт

Название, частота выборки, точность → **Экспорт .skyc**. Также CSV, импорт
`.skyc` и отправка в запущенный просмотрщик.
